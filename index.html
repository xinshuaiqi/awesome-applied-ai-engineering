Enterprise Anti-Patterns We Explicitly Call Out

Agentic Loops
Never for simple lookup tasks — causes severe latency and token burn. Use direct retrieval instead.
GraphRAG Everywhere
Overkill for flat QA on PDFs. Reserve for deeply interconnected domains (legal, medical, financial).
Local SLMs for Complex Reasoning
Without fallback routing, small models fail on multi-step enterprise reasoning. Always build a fallback.
Single-Model Architecture
Any production system needs routing, fallback, and cost optimization across model tiers. Lock-in is risk.
